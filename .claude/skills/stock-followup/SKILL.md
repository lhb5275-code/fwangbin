# F/U(실적 리뷰) PPT 작업 절차

`stock-study/`의 도구를 쓴다.

시작하기 전에 다음 파일을 모두 읽는다.
- `stock-study/STYLE_FU.md`: F/U 양식
- `stock-study/STYLE.md`: 공통 스타일
- `stock-study/companies/LITE_fu_sample/deck_fu.yaml`: 완성 예시
- `.claude/skills/stock-study/SKILL.md`: 데이터·이미지·확인 절차

공통 규칙:
- 사진은 고화질로 쓴다.
- 화면 전환 효과는 넣지 않는다.
- 대본에 `(나)` 같은 표시를 쓰지 않는다.
- 막대 숫자가 가려지지 않게 한다.

## 1. 지난 분석 찾기

- `stock-study/companies/<TICKER>/`에 지난 원고(`deck*.yaml`)와 `output/`의 지난 덱이 있는지 본다.
- 있으면 지난 분석 날짜, 당시 주가, 당시 회사 가이던스, 지켜보자고 했던 점을 메모한다. 이번 덱의 회고 장과 총정리에 쓴다.
- 지난 덱 표지·주가 장 이미지: `python render_slide.py output/<지난 덱>.pptx companies/<T>/img/prev.png --slide 1`
- 지난 분석이 없으면 사용자에게 지난 분석 시점·당시 주가를 묻거나, 회고 장을 빼고 진행한다.

## 2. 데이터

```bash
cd stock-study && python fetch_data.py <TICKER>     # 2년치 일봉 포함
```

- 실적 발표 시점 기준으로 만들 때는 차트에 `until: "YYYY-MM-DD"`를 단다. 그 이후 분기·주가가 섞이지 않게 하기 위해서다. 주가 장에는 `date:`로 기준일을 표시한다.
- 과거 기준일 주가 화면의 시가총액은 자동으로 계산하지 않는다. 확인한 값을 `market_cap:`으로 직접 넣는다.

## 3. 조사

| 내용 | 출처 |
|---|---|
| 이번 분기 실적 | 8-K Exhibit 99.1(실적 보도자료), 10-Q, 주주서한 |
| 지난 분기에 회사가 낸 이번 분기 가이던스 | 지난 분기 실적 보도자료의 Outlook / Guidance 부분 |
| 다음 분기 가이던스 | 이번 실적 보도자료·어닝콜 |
| 최근 4분기 Non-GAAP 영업이익률·EPS | 각 분기 보도자료의 Non-GAAP 표 |
| CEO 한마디 | 어닝콜 대본 첫 발언(prepared remarks)에서 이번 분기의 핵심 메시지 문장 |
| 키워드 딥다이브 | CEO가 강조한 제품·기술의 회사 제품 페이지, IR 자료 |
| 주요 뉴스 | 분기 중 보도자료 (파트너십, 인수, 지수 편입, 대형 계약) |
| Q&A | 어닝콜 대본 Q&A에서 5~7개 |
| 목표주가·밸류에이션 | MarketBeat, StockAnalysis, TipRanks 등. 조회일을 `date:`로 표시 |
| 증권사 리포트 | 국내 증권사 해외주식 리포트, 보도된 목표가 변경 (증권사명·날짜와 함께) |

- 사용자가 실적발표 자료 PDF를 주면 `python fetch_media.py pdf <PDF> companies/<T>/img/ir`로 사진을 원본 해상도로 꺼낸다.
- 표지·성장동력·목표 재무모델·마지막 장은 `render_slide.py`처럼 PDF 페이지를 고해상도(200dpi 이상)로 그려서 쓴다: `pdftoppm -png -r 200 -f N -l N`.

## 4. 원고 — `companies/<TICKER>/deck_fu_<분기>.yaml`

`STYLE_FU.md`의 '슬라이드 구성' 순서를 따른다. 보통 30~45장이다.

- **판정:** 가이던스 범위 안이면 '충족', 상단을 넘으면 '상회', 하단 미달이면 '하회'로 쓴다. 일부만 상회하면 '(부분적인) 어닝 서프라이즈'라고 쓰고 이유를 대본에 적는다.
- **CEO 한마디:** 2~4줄로 끊고, 다음 장들에서 깊게 다룰 키워드를 `[[ ]]`로 표시한다.
- **재무제표:** 손익은 분기 YoY, 재무상태는 회계연도 말 대비, 현금흐름은 연초 누적 기준으로 쓴다 (10-Q 비교 기준과 같음).
- **가이던스 차트:** 최근 4분기 실적과 다음 분기 가이던스를 `type: guidance`로 그린다. 가이던스는 범위 그대로 라벨에 쓰고, 막대 높이는 중간값으로 한다.
- **총정리:** 실적 판정 → 재무 체크 → 이번 분기 이벤트 → 성장동력·중장기 목표 → 인상 깊었던 점·지켜볼 점·리스크 순서로 쓴다. 지난 분석에서 지켜보자고 했던 점이 어떻게 됐는지도 넣는다.
- **대본:** `STYLE_FU.md`의 '대본 문장 틀'을 따른다.

## 5. 만들고 확인하고 전달

- `python build_deck.py companies/<T>/deck_fu_<분기>.yaml` 실행 후 validate를 돌리고, 모든 장을 렌더링해서 본다. 절차는 stock-study와 같다.
- 확인할 것: 인용문이 사진에 묻히지 않는지, 가이던스 차트 라벨이 겹치지 않는지, 기준일이 모든 시세 장에 있는지.
- 원고·이미지·결과물을 커밋·푸시하고 .pptx를 보낸다.
- 답변에 짧게 정리할 것: 핵심 결과(가이던스 대비 판정, 다음 분기 가이던스), 지난 분석 대비 달라진 점, 확인하지 못한 수치.
