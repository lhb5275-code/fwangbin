# 타액선 3D 아틀라스

이하선·악하선·설하선·소타액선의 구조와 주요 기능을 보여 주는 3D 시뮬레이션입니다 (Three.js).

- **스크롤**: 섹션마다 카메라가 해당 타액선으로 이동하고, 나머지 구조는 흐리게 표시됩니다.
- **드래그**: 모델을 회전합니다. `시점 초기화` 버튼으로 기본 시점으로 돌아갑니다.
- **커서 올리기(모바일은 탭)**: 타액선, 도관(스텐센관·와르톤관·바르톨린관·리비누스관), 안면신경, 주변 근육의 주요 기능이 툴팁으로 나타납니다.
- 상단 체크박스로 피부·근육·안면신경·뼈 레이어를 켜고 끌 수 있습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. Three.js(r128)와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
