# F/U(실적 리뷰) 양식

이미 분석한 기업의 새 분기 실적을 다시 정리할 때 쓰는 양식입니다. '루멘텀 2026-3분기 실적 리뷰' 예시 덱(42장)에서 뽑은 규칙입니다. 처음 분석할 때 쓰는 [STYLE.md](STYLE.md)의 기본 스타일을 그대로 따르고, 아래 요소를 더합니다.

## 신규 분석 양식과 다른 점

| | 신규 분석 (STYLE.md) | F/U 실적 리뷰 (이 문서) |
|---|---|---|
| 목적 | 회사를 처음부터 소개 | 지난 분석 이후 무엇이 바뀌었나 |
| 표지 | 회사 로고 + "회사명 기업분석" | 주제 사진 전면 + 노란 회사명 + 후킹 문구 ("$1,300 간다?") |
| 앞부분 | 사업한줄평·역사·CEO·매출 구성 | 지난 분석 회고 → 주가 흐름 → 실적발표 자료 표지 |
| 실적 비교 기준 | 전년 대비(YoY) | 회사가 지난 분기에 낸 가이던스 대비 (충족·상회·하회) |
| 주제 | 사업 전반 | CEO 한마디에서 뽑은 키워드 하나를 깊게 |
| 가이던스 | 연간 가이던스 | 최근 4분기 추이 + 다음 분기 가이던스 차트 |
| 마무리 | 투자 포인트·리스크 | 총정리: 실적 판정 → 재무 → 이벤트 → 성장동력 → 인상 깊은 점·지켜볼 점·리스크 |
| 끝 장 | "감사합니다" 큰 글자 | 회사 IR 자료 마지막 장 전면 + 흰 탭 "감사합니다" |

공통 규칙도 그대로 지킵니다.

- 사진은 고화질로 씁니다.
- 화면 전환 효과는 넣지 않습니다.
- 대본에 `(나)`·`(사)`·`(모핑)` 같은 표시를 쓰지 않습니다.
- 막대 숫자가 가려지지 않게 합니다.

## 글꼴과 색 (추가분)

| 용도 | 글꼴 / 색 |
|---|---|
| 표지 회사명 | 여기어때 잘난체 고딕, 노랑, 약 170pt (검은 번짐 효과로 사진 위에서도 또렷하게) |
| 표지 후킹 문구 | 여기어때 잘난체 고딕. 숫자·핵심어는 노랑 크게, 나머지는 흰색 70% 크기 |
| CEO 인용문 | 에스코어 드림 6 Bold 40pt 흰색, 핵심어 노랑 48pt, 앞뒤에 “ ” |
| 기준일 표기 | 에스코어 드림 4 Regular 16pt 흰색, 오른쪽 위 `(2026-05-10)` |
| 가이던스 차트 | 막대 하늘색 `#CAEEFB`·가이던스 막대 살구색 `#F6C6AD`, 성장률 노랑, 영업이익률 빨강 `#FF0000`, EPS 초록 `#00B050` |
| 유보 표현 | '(부분적인) 어닝 서프라이즈'처럼 단서를 다는 말은 살구색 `((…))` |

## 로고 쓰는 법

- **제목 탭:** 왼쪽에 밝은 배경용 로고를 넣습니다. 신규 분석 양식과 같습니다.
- **표지:** 오른쪽 아래에 흰색 로고를 작게 넣습니다 (`logo_small`). 어두운 로고만 있으면 흰색으로 바꿔서 씁니다.
- **장 전환 사진:** 회사 로고가 보이는 사진을 고릅니다 (실적발표 자료 표지, 행사 부스, 사옥, 보도자료 이미지).
- **끝 장:** 회사 IR 자료의 마지막 장(로고가 들어간 "Thank you" 화면)을 전면에 깔고, 흰 탭에는 로고 없이 "감사합니다"만 씁니다.

## 사진 쓰는 법

| 자리 | 사진 |
|---|---|
| 표지 | 회사가 속한 산업을 보여주는 분위기 사진 (데이터센터 복도, 공장, 발전소 등). 화면 전체에 깔고 살짝 어둡게 |
| 지난 분석 회고 | 지난 덱의 표지나 주가 화면을 이미지로 (`render_slide.py`) + 당시·현재 주가 비교 막대 |
| 실적발표 자료 표지 | 회사 IR 발표자료 첫 장을 화면 전체에 |
| CEO 한마디 | CEO 인물 사진. 오른쪽 위아래를 꽉 채움 |
| 키워드 딥다이브 | 제품 사진·구조도 한 장씩. 한 장에 제품 하나, 제목 아래 제품 이름 한 줄 |
| 사업성과 뉴스 | 보도자료 이미지 (파트너십, 인수, 지수 편입 등) |
| 가이던스 앞 | 행사 사진(투자자의 날, 학회 부스 등)을 화면 전체에 깔아 장을 바꿈 |
| 가이던스 | IR 자료의 성장동력·중장기 목표·목표 재무모델 슬라이드 이미지 |
| 끝 장 | IR 자료 마지막 장 |

다른 회사 자료에서 가져온 그림에는 오른쪽 위에 `(출처: ○○ IR)`을 답니다.

## 슬라이드 구성 (예시 덱 순서)

| # | 슬라이드 | 생성기 `type` |
|---|---|---|
| 1 | 표지: 주제 사진 + 회사명 + 후킹 문구 + 작은 로고 | `fu_cover` |
| 2 | 지난 분석 회고: 지난 덱 이미지 + 당시 주가 → 현재 주가 | (일반) 이미지 + 막대 |
| 3 | 주가 흐름 (기준일) | (일반) `chart: {source: price_1y, until: …}` + `date` |
| 4 | 실적발표 자료 표지 전면 + "왜 올랐을까요?" | `full_image` |
| 5 | N분기 실적: 매출·EPS vs 회사 가이던스 (충족/상회/하회) + 분기 매출 차트 | (일반) |
| 6 | CEO 한마디 (어닝콜 첫 발언에서 핵심 문장) | `quote` |
| 7~12 | 키워드 딥다이브 (CEO가 강조한 단어, 제품 하나씩) | (일반) 이미지 |
| 13~16 | 사업성과: 부문별 실적 → 주요 뉴스 (한 장에 하나) | (일반) |
| 17~19 | 손익계산서(YoY) · 재무상태표(회계연도 말 대비) · 현금흐름표(연초 누적) | (일반) `layout: right` + 표 |
| 20 | 행사 사진 전면 → 가이던스로 전환 | `full_image` |
| 21~23 | 가이던스: IR 자료 성장동력·중장기 목표 | (일반) 이미지 |
| 24 | 다음 분기 가이던스 차트 (최근 4분기 + 가이던스) | `guidance` |
| 25~32 | Q & A (5~7개) | `section` + `qa` |
| 33~35 | 목표주가 · 목표주가 변경 · 밸류에이션 (모두 기준일) | (일반) + `date` |
| 36~41 | 총정리 (여러 장) | (일반) |
| 42 | IR 마지막 장 + "감사합니다" 탭 | `full_image` + `tab` |

## 판정 용어

| 비교 대상 | 용어 | 기준 |
|---|---|---|
| 회사 가이던스 | 충족 | 가이던스 범위 안 |
| 회사 가이던스 | 상회 | 가이던스 상단 초과 |
| 회사 가이던스 | 하회 | 가이던스 하단 미달 |
| 컨센서스 | 상회 / 부합 / 하회 | |

일부 지표만 상회하면 '(부분적인) 어닝 서프라이즈'라고 쓰고, 그 이유를 대본에서 설명합니다.

## 대본 문장 틀

- 시작: "오늘은 2026년 5월에 발표된 ○○의 3분기 실적을 정리해드리겠습니다."
- 회고: "3달 전에 2분기 실적을 분석했는데 그때 주가가 ○○달러였습니다."
- 주가: "2026년 5월 10일 기준 주가는 ○○달러이고 시가총액은 ○○억 달러입니다."
- 질문: "1년 동안 주가가 무려 14배나 올랐는데 그 이유가 뭘까요?"
- 인용문: 인용문을 그대로 읽은 뒤 "어닝콜 초반에 ○○ CEO가 한 말입니다."
- 총정리 마지막: 인상 깊었던 점 → 지켜볼 점 → 리스크 → "현명한 투자하시길 바라겠습니다."
- 끝: "이상 ○○의 2026 회계연도 3분기 실적 리뷰를 마치겠습니다. 영상이 도움되셨다면 구독, 좋아요, 댓글 꼭 부탁드립니다."
